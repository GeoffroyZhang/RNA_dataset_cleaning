# Objectif ?

Voici un exemple de script codé en langage python vous permettant d'exploiter le jeu de données RNA 2025 publié par data.gouv.fr dans une optique d'analyse historique ou autre sur les associations chinoises répertoriées en France.

## Ressources 

Vous trouverez les jeux de données à l'adresse suivante : https://www.data.gouv.fr/datasets/repertoire-national-des-associations

## Langages utilisés

- Python

## Cloner le dépôt

git clone git@github.com:GeoffroyZhang/RNA_dataset_cleaning.git

## Structure du projet

- `rna_waldec_fusion.py` : script python permettant la fusion de l'ensemble des fichiers CSV contenu dans le dossier RNA 2025, soit 104 fichiers.
- `rna_nettoyage.py` : script contenant le filtrage pour obtenir le résultat voulu.

- `rna_waldec_assoChineFiltre.csv` : résultat obtenu via le script python.
